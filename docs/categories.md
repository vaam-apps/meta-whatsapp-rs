## How to read the table

- **Status** is `library / service`: **done**; **partial**, when a
  documented part of the category is missing (the notes say which) or
  the service carries only part of it; **gap**, when nothing is built
  yet. A side is done only when every parity row the category cites is
  done there, and a gap only when every one is a gap (n/a rows aside).
  The [roadmap](roadmap.md) items that bring the service's part are in
  parentheses: those of the cited rows. There is no n/a here: a part
  parity marks n/a is named in the notes.
- **Meta docs area**: paths relative to
  `https://developers.facebook.com/documentation/business-messaging/whatsapp/`;
  **(nm)** marks a page the mirror cannot fetch, as in
  [parity.md](parity.md#how-to-read-the-table).
- **Coverage rows** link to the rows of [coverage.md](coverage.md); every
  one of its rows 1–34 appears at least once.
